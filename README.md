**Course:** IT318 - Web Development

## 🌐 Live Deployment
**Link:** [https://allysa-gorduiz-final-exam.onrender.com]

## 🛠️ Project Overview
This is a Full-Stack Web Application developed for the IT318 Final Examination. It allows for complete Student Record management (CRUD) using a cloud-hosted MySQL database.

## 🚀 Technical Stack
*   **Frontend:** EJS (Embedded JavaScript Templates) with a Light Glassmorphism UI.
*   **Backend:** Node.js & Express.
*   **Database:** Aiven Cloud MySQL (defaultdb).
*   **Deployment:** Render.

## 📂 Project Structure
*   `crud_final_exam.js` - The main server and API logic.
*   `views/` - Contains the frontend EJS files.
*   `package.json` - Lists the project dependencies.
